## 💻 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/sinan-rahman-ak/my-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd my-portfolio
   ```
3. Open `index.html` in any web browser, or serve it using Python:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.
